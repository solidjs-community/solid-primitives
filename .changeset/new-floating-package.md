Initial release of `@solid-primitives/floating`: `computePosition` and `computePositionFromRects` (placement, offset, flip, shift, size, arrow, RTL, boundaries), `makeAutoUpdate`, the reactive `createFloating`, and size CSS variable helpers. `computePosition` handles transformed containing blocks for `strategy: "fixed"` and scaled offset parents.
